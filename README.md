# Geçmiş Zaman Dedektifi

İngilizce düzensiz fiiller için 400 soruluk, 20 quizden oluşan bağımsız çalışma sayfası. Yalnızca HTML, CSS ve JavaScript kullanır; veritabanı yoktur.

Çocuklar adlarını yazarak aynı tarayıcıda kaldıkları quizden devam eder. İlerleme `localStorage` içinde tutulur; cevaplar ve oturum puanları saklanmaz. Soru ve cevaplar `questions.js` dosyasındadır.

Bu sayfa Türkçe ve Almanca egzersizlerine bağlantı veya bu egzersizlerin içerik dosyalarını içermez.
